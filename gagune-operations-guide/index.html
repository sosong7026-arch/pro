04

온라인 CS 처리 가이드

브랜드 담당자에게 전달할 기본 흐름입니다. 권한 설정 후 적용합니다. 화면별 캡처와 예시 문의를 보완해 최종 가이드로 전달합니다.

브랜드 운영안

BRAND CS WORKFLOW

문의 접수부터
처리 결과까지.

브랜드 담당자가 자사 문의를 확인하고, 진행 내용을 게시판에 남기는 방식으로 운영합니다.

답변 및 처리 이력 기록
  1. 1

    부계정으로 로그인

    개별 전달받은 계정으로 접속합니다. 접속 오류는 계정 관리 담당자에게 전달합니다.

  2. 2

    담당 게시판에서 문의 확인

    자사 상품명·주문정보·문의 유형과 첨부사진을 확인합니다.

  3. 3

    접수 안내 및 추가 정보 확인

    A/S·교환·반품 유형을 구분하고, 필요한 사진이나 정보를 요청합니다.

  4. 4

    기준 확인 후 처리 방법 안내

    합의된 기준에 따라 가능 여부·비용·일정을 안내합니다. 환불 실행은 지정 담당자에게 전달합니다.

  5. 5

    진행 상황과 최종 결과 기록

    수거·수리·재배송 일정과 결과를 남기고, 고객에게 완료 내용을 안내합니다.

관리자 사전 설정 · 게시판 답변 권한
  1. 관리자 설정 → 운영자설정 → 운영자 계정 관리에서 해당 부운영자를 선택합니다.
  2. PC 어드민 권한 → 상세권한 → 게시판관련 → 게시판별 상세권한에서 사용할 게시판을 선택합니다.
  3. 브랜드 담당 계정으로 로그인해 읽기·답변 작성과 조회 범위를 확인합니다.

위 경로는 부운영자 권한 안내입니다. 공급사 운영자는 이용 가능한 메뉴와 권한 범위를 별도 확인하세요. 브랜드별 문의 자동 배정은 이 페이지에서 구현한 기능이 아닙니다.

05

브랜드 부계정 이용방법

브랜드 담당자가 직접 따라 하는 순서입니다. 실제 메뉴명은 부여한 계정과 권한에 맞춰 확정합니다.

계정별 시연 필요

  1. 전달받은 계정·접속주소 확인

    브랜드명, 담당자, 관리자 접속주소, 아이디, 사용 가능한 메뉴를 확인합니다. 계정정보는 담당자에게 개별 전달합니다.

  2. 부계정 로그인 및 초기 설정

    안내받은 주소에서 로그인합니다. 초기 비밀번호 변경 안내가 있으면 변경하고, 접속·이용 문의는 소영님에게 전달하고, 추가 권한이나 시스템 오류는 관리자 확인을 거칩니다.

  3. 자사 상품·주문 조회 범위 확인

    브랜드 담당 메뉴에서 필요한 상품·주문을 찾을 수 있는지 확인합니다. 타 브랜드 정보가 보이면 담당자에게 알립니다.

  4. 담당 게시판의 문의 확인

    자사 문의의 상품명·주문정보·사진을 확인합니다. 담당 메뉴가 보이지 않으면 권한 설정 여부를 확인받습니다.

  5. 답변 작성 및 저장 결과 확인

    CS 가이드에 따라 답변하고, 저장한 답변이 문의 화면에 정상 반영됐는지 확인합니다. 처리 결과도 기록합니다.

  6. 예외 상황 전달 및 로그아웃

    권한 부족·주문 불일치·환불 실행 등 직접 처리할 수 없는 건은 지정 담당자에게 전달합니다. 이용 후 로그아웃합니다.

최종 전달 자료 : 관리자 접속주소 + 담당 메뉴 안내 + 단계별 화면 캡처 + CS 가이드 + 접속·권한 문의 담당자
로그인 정보는 이 안내 페이지에 적지 않고 개별 전달합니다.
